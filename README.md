# Libft

Implementation of a small C library containing commonly used functions from the standard C library.

The project was developed as part of the 42 curriculum and was one of the first projects focused on working directly with memory, strings and pointers in C.

## Functions

The library includes implementations for:

* Character checks and conversions
* String handling
* Memory manipulation
* String comparison and searching
* Dynamic memory allocation
* Number conversion

## Build

```bash
make
```

This creates `libft.a`.

Available Make targets:

```bash
make
make clean
make fclean
make re
```
